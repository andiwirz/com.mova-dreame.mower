# Native no-go zone mission phases without a garage / Phasen-Sperrzonen ohne Garage

## EN
All nine zone policies are independent of a garage or gate: permanent; 3/7/14 days; departure only; departure+mowing; mowing only; mowing+return; return only. The mower phase is determined from native state/position observations, and zone policy changes are tracked for a safe checkpoint. **Important physical limitation:** the firmware requires task-free IDLE (not just PAUSED) and confirmed stillness before a native map modification; the new polygon must be independently verified by MAPD. This is not automatically available at every phase transition initiated in the original vendor app. Homey-started mowing conservatively pre-arms protected areas before movement. If no safe checkpoint is observed, no hazardous native write is attempted and the UI shows a deferred/unconfirmed transition. Garage Mode is needed only for gate-specific emergency and departure/return interlocks, not zone policy selection.

## DE
Alle neun Sperrzonen-Regeln funktionieren grundsätzlich ohne Garage: dauerhaft, 3/7/14 Tage, nur Ausfahrt, Ausfahrt + Mähen, nur Mähen, Mähen + Rückkehr, nur Rückkehr. Homey wertet die native Fahrphase aus und merkt erforderliche Änderungen für einen sicheren Prüfpunkt vor. **Physische Grenze:** Der Mäher muss ohne aktiven Auftrag (nativ IDLE, nicht nur PAUSED) bestätigt stillstehen; anschließend muss MAPD die native Geometrie nachweisen. Besonders beim Start aus der Original-App liegt dieser Prüfpunkt nicht zu jeder Phasenänderung vor. Beim Start aus Homey werden Schutzbereiche vorsorglich vor Fahrtbeginn aktiviert. Ohne Prüfpunkt bleibt die Änderung vorgemerkt/unbestätigt; es erfolgt kein unsicherer Karten-Schreibversuch. Der Garagenmodus ist nur für Tor-Sicherheitslogik und zugehörige Fahrabläufe nötig, nicht für die Sperrzonen-Regeln.

## 02 Nov 2026 — phase policy vs. protective pre-arming / Fahrphase vs. Schutz-Voraktivierung

**EN:** A phase selection describes when the zone is needed. Because this mower cannot alter the native map while a mission is running, `mowing` and `mowing_return` protections are deliberately **armed already at the station and retained during departure**. This is a conservative safety exception, **not an exact mowing-only hardware window**. The UI now says so visibly. `return` (return only) is **not pre-armed on a new departure**; at an actual safe, task-free return checkpoint Homey may add it and verifies the real map. If no such checkpoint is available, it remains pending/unconfirmed. Phase rules are independent of Garage Mode; a phase label never permits an edit to a moving mower. No additional stop is needed if the native geometry already matches the requested phase.

**DE:** Die Phasenauswahl beschreibt, **wann der Schutz benötigt wird**. Da der Mäher bei laufendem Auftrag keine native Kartenänderung erlaubt, werden die Schutzregeln `mowing` (nur Mähen) und `mowing_return` (Mähen + Rückkehr) bewusst **schon in der Station voraktiviert und während der Ausfahrt beibehalten**. Das ist eine Sicherheitsausnahme, **kein sekundengenau auf die Mähphase begrenzter nativer Zeitraum**. Die Editoren zeigen diesen Hinweis jetzt sichtbar an. `return` (nur Rückkehr) wird **vor der Ausfahrt nicht mehr vorsorglich aktiviert**; die Aktivierung ist erst an einem echten, aufgabenfreien Rückkehr-Prüfpunkt mit MAPD-Nachweis möglich. Fehlt dieser, wird die Änderung nicht als erfolgt angezeigt. Keine Regel ist an eine elektrische Garage gebunden. Ohne notwendige native Änderung wird kein zusätzlicher zonenbedingter STOP ausgelöst.
